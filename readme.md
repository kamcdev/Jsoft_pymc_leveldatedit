# 介绍

这是一款使用python开发的Minecraft存档level.dat编辑器

提供了GUI，基于pyside6

提供读取模式（使用中文展示数据内容）和编辑模式（具体编辑每个规则）

支持将level.dat的nbt数据转换为json原数据，也能重新打包为level.dat

整个项目通过分析Minecraft 1.21.8和26.1源代码，实现了相关功能

vibe coding弄出来的，使用的辅助ai为MiniMax-M2.5
